 # CapFlow

Flutter-приложение для учёта личных финансов и инвестиций. Позволяет вести счета в разных валютах, отслеживать финансовые инструменты (деньги, депозиты, акции, облигации, криптовалюта, кредиты, прочие активы), фиксировать операции, планировать регулярные события и анализировать доходы/расходы.

## Возможности

### Счета и инструменты
- Счета произвольных типов (обычный, брокерский, криптовалютный) с настройками отображения, исключением из общего итога и цветовой маркировкой (12 цветов)
- Инструменты: деньги в разных валютах, депозиты, акции, облигации, криптовалюта, кредиты, прочие активы
- Полный жизненный цикл депозита и кредита (открытие, план процентов/погашений, закрытие)

### Операции и инвестиции
- Покупка/продажа биржевых инструментов и криптовалют с комиссиями и НКД
- Подсказки тикеров из интернета: **MOEX ISS** (акции и облигации, с ценой, купоном, номиналом, НКД) и **CoinGecko** (криптовалюты) с локальным кэшем и fallback на данные из БД
- Переводы между инструментами, в том числе с конвертацией валют (курс из введённых сумм, сохраняется в справочник курсов)
- **Реализованная прибыль/убыток** при продаже: средняя цена считается из истории операций, результат фиксируется отдельной операцией

### Планировщик
- Регулярные события: еженедельно, ежемесячно (в тот же день / в выбранный день), ежеквартально, каждые полгода, ежегодно
- Дивиденды и купоны облигаций создаются в планировщике автоматически и пересчитываются при изменении количества инструмента

### Аналитика
- Отчёт по месяцам: доходы, расходы, бюджет плановых событий; графики на `fl_chart`
- Обороты за 30 дней по счёту; переводы между своими счетами не искажают доходы/расходы

### Прочее
- **Вход по PIN-коду** (включается в настройках; 4 цифры; автоблокировка после таймаута бездействия: сразу / 1 мин / 5 мин)
- **Резервное копирование и восстановление**: база целиком сохраняется через системный диалог и восстанавливается с перезапуском
- Тёмная / светлая / системная тема
- Мультиязычные подписи интерфейса — русский
- Local-first: все данные хранятся локально в SQLite

## Технологии

| Компонент | Технология |
|---|---|
| Фреймворк | Flutter (Material 3) |
| Состояние | flutter_bloc ^9.1.1 |
| Навигация | go_router ^15.0.0, adaptive_navigation |
| База данных | sqflite (SQLite, локально, миграции) |

| Идентификаторы | UUID v7 |

Основная целевая платформа — Android; также собирается под Windows, Linux, macOS, Web, iOS.

## Быстрый старт

```bash
flutter pub get
flutter run
```

При запуске автоматически инициализируется локальная база данных и применяются миграции. Для установки на Android-устройство по Wi-Fi:

```bash
adb connect <ip>:<порт>
flutter build apk --debug
adb -s <ip>:<порт> install -r build/app/outputs/flutter-apk/app-debug.apk
```

## Структура проекта

```
lib/
├── core/            # Инфраструктура: приложение/роутер, БД, тема, виджеты, утилиты
│   ├── widgets/     # Общие виджеты (fade-страница и др.)
│   ├── utils/       # Расчёты и хелперы (форматирование, next occurrence, PIN/тосты)
│   └── theme/       # Светлая/тёмная темы
├── data/            # Модели, репозитории, внешние источники (MOEX, CoinGecko)
├── feature/         # Фичи
│   ├── account/     # Счета, формы операций (доход/расход/перевод/деньги/депозит/кредит/инвестиции)
│   ├── activity/    # Список и детали операций
│   ├── auth/        # Сессия, вход, PIN-блокировка
│   ├── event/       # Планировщик регулярных событий
│   ├── report/      # Аналитика по месяцам
│   ├── settings/    # Настройки (тема, валюта, безопасность, бэкап)
│   ├── tool_detail/ # Детальные экраны инструментов
│   └── tools/       # Домен тулов
├── widgets/         # Переиспользуемые виджеты (аватары, значения)
└── main.dart        # Точка входа
```

Каждая фича содержит свои `data`, `logic` (BLoC/Cubit) и `presentation`. Подробное описание архитектуры и соглашений по коду — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Архитектура

- **Feature-based** структура: `lib/feature/<имя>/{data, logic, presentation}`
- **BLoC** как основной паттерн управления состоянием
- **Repository pattern** для доступа к данным; внешние провайдеры изолированы в `lib/data/source/`
- **Local-first**: без бэкенда, всё в локальной SQLite; миграции схемы последовательные
- **Event replay**: количества и стоимости инструментов выводятся переигрыванием операций из БД — операции единственный источник истины
- Обмены между своими активами помечаются флагом перевода и не искажают доходы/расходы; выгода/убыток фиксируются отдельными операциями
